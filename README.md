# JavaScript Mastery — Beginner to Interview Ready

A structured JavaScript learning workspace for VS Code. Each topic has a starter file with learning prompts; implementations are intentionally left for you to write.

## Getting started
1. Extract the ZIP.
2. Open the `JavaScript-Mastery` folder in VS Code.
3. Install Node.js (LTS) to run `.js` files.
4. Open a terminal and run `node 01-JS-Fundamentals/02-variables.js`.
5. Start with folder 01, work sequentially, and log your progress in folder 14.

## Suggested 90-day roadmap
- Days 1–10: Fundamentals and functions
- Days 11–22: Arrays, strings, objects
- Days 23–34: Advanced JavaScript
- Days 35–41: Asynchronous JavaScript
- Days 42–50: DOM and modern JavaScript
- Days 51–75: DSA and interview practice
- Days 76–90: Projects, testing, and revision

DSA practice can also be started earlier, once you are comfortable with loops and arrays.

## Notes
The files are starter templates, not a completed course. Each topic is designed for hands-on practice.
